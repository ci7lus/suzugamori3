# suzugamori3

Swarm のチェックインを "I'm at..." 形式で共有するためのアプリ

## 起動

```sh
pnpm install --frozen-lockfile
pnpm d
```

## 環境変数

| 環境変数                    | 設定する内容                   |
| --------------------------- | ------------------------------ |
| `APP_ORIGIN`                | アプリのオリジン               |
| `VITE_FOURSQUARE_CLIENT_ID` | Foursquare OAuth Client ID     |
| `FOURSQUARE_CLIENT_SECRET`  | Foursquare OAuth Client Secret |
